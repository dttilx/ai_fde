- 未发现 tests 中捕获业务异常后返回预期报告、无条件 assert True、skip/xfail 掩盖失败的写法。Worker.run_once 的 True 表示处理过一个任务；执行成功必须另检查 Job.status，不能以该返回值替代成功断言。
